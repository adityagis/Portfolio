# Aditya Kumar Jha: GIS Engineer Portfolio

**Live site: https://adityagis.github.io/Portfolio/**

Portfolio of **Aditya Kumar Jha**, a GIS engineer at Survey of India (Geodetic & Research Branch, Dehradun). I process GNSS CORS data from 1023+ reference stations with GAMIT/GLOBK and PRIDE PPP-AR, write Python automation for geodesy and GIS workflows, and have worked on LiDAR, hyperspectral and flood risk mapping at DRDO.

## Built with

Plain HTML, CSS and JavaScript. No framework and no build step, hosted on GitHub Pages.

- Search: `index`/`follow` meta, canonical URLs, Open Graph and Twitter cards, `sitemap.xml`, `robots.txt`
- Structured data: schema.org `Person`, `WebSite`, `ProfilePage`, `CollectionPage`, `ProfessionalService`, `CreativeWork` and `BreadcrumbList` (JSON-LD)
- AI assistants: [`llms.txt`](https://adityagis.github.io/Portfolio/llms.txt) summary and [`llms-full.txt`](https://adityagis.github.io/Portfolio/llms-full.txt) full text
- Accessibility: skip link, landmarks, keyboard navigation, reduced-motion support

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
